## นำขึ้น GitHub Pages
1. สร้าง Repository ใหม่ในบัญชี GitHub ของคุณ
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
3. ไปที่ Settings → Pages
4. เลือก Deploy from a branch
5. เลือก `main` และ `/ (root)`
6. กด Save
7. รอ GitHub สร้างเว็บไซต์
